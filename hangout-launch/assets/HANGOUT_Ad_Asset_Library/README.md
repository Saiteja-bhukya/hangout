# HANGOUT – Advertisement Asset Library

Supporting assets for the 45-second HANGOUT launch film. Use them alongside the 20 customer-app ad screens on the "Hangout Advertisement" canvas.

## Honest status
- **Figma:** the Figma file "Hangout Advertisement" exists but is still empty. The Figma connection hit the Starter-plan tool-call limit before anything could be drawn. Every SVG here drags straight into Figma as editable vectors; PNG and JPG files drop in as images.
- **Logo:** HANGOUT had no finished logo file. This kit is built from the H-with-a-point-of-light mark on the app's splash screen. The wordmark is custom vector strokes, so it needs no font file.
- **Entertainment visuals:** the stylised 3D renders and AI photo drafts have been removed. Use the licensed transparent images listed in RECOMMENDED_TRANSPARENT_IMAGES.md instead.
- **Audio:** everything was synthesised from scratch in code, with no samples or third-party loops, so there are no licence issues. It has not been listened to by a person. Treat the music as a draft bed; a licensed track will sound richer.
- **Fonts:** Rajdhani and Urbanist (Google Fonts, SIL Open Font License). The files could not be downloaded in this workspace, so get them from fonts.google.com/specimen/Rajdhani and fonts.google.com/specimen/Urbanist. Text-bearing SVGs keep editable text and show the right font only once it is installed or loaded.
- **Transparency:** every PNG was checked for a transparent background. The only opaque one is the full-bleed app icon, which is opaque by design.

## Film timeline (from the script)
0–5 teaser · 5–11 reveal · 11–19 discover · 19–27 make it happen · 27–36 play, progress, unlock · 36–41 big picture · 41–45 brand reveal.

- **HANGOUT_Assets_2_Motion_Graphics.zip:** 03_Motion_Graphics

- **HANGOUT_Backgrounds_4K_9x16.zip:** 04_Backgrounds, portrait 2160×3840 files only
